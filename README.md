## ☢ О проекте

**«Бункер»** — браузерная многопользовательская игра, в которой участники пытаются попасть в убежище после глобальной катастрофы. Мест на всех не хватит: придётся раскрывать характеристики персонажей, спорить, договариваться и голосовать.

Игра запускается прямо в браузере. Устанавливать отдельную программу не нужно. Для сетевой игры используется бесплатный облачный Worker — создателю комнаты не требуется держать компьютер включённым.

> **Статус этой ветки:** подготовлен переход на серверную архитектуру Cloudflare. Перед слиянием с main нужно один раз опубликовать Worker и указать его адрес в cloudflare-config.js. Пошаговая инструкция — [cloudflare/SETUP.md](cloudflare/SETUP.md). Пока настройка не выполнена, текущая публичная версия на main остаётся без изменений.

## Как начать игру

1. Откройте [сайт игры](https://netomur.github.io/Bunker/).
2. Введите имя. Авторизация через Discord необязательна.
3. Нажмите **«Создать комнату»** и выберите набор **«Стандартный»**.
4. Отправьте друзьям 8-символьный код комнаты.
5. Друзья вводят код в разделе **«Войти в комнату»**. Ведущий запускает партию, когда все готовы.

В комнате может находиться до 16 участников. Состояние партии хранится на облачном сервере и не зависит от вкладки создателя комнаты.

## 🎮 Как проходит партия

**Лобби.** Создатель комнаты становится ведущим. Он может передать роль другому игроку, решить, участвует ли сам ведущий, и установить количество участников, которые должны остаться в финале.

**Раздача персонажей.** При старте каждому игроку случайно назначаются характеристики. Также для всей партии выбираются сюжет, размер бункера и планировка помещений.

**Раунды.** Ведущий чередует показ характеристик и голосование. В фазе показа каждый живой участник раскрывает одну свою карточку. В голосовании игроки выбирают кандидата; чужой выбор скрыт до завершения голосования ведущим.

**Выбывание.** Ведущий отмечает игрока, который покидает убежище. При необходимости его можно вернуть. Специальные возможности персонажей могут повлиять на ход партии.

**Финал.** Когда остаётся заданное количество участников, игроки открывают оставшиеся характеристики, а ведущий отвечает на вопросы о состоянии бункера.

## 🧍 Характеристики персонажа

У каждого игрока 12 категорий:

| Категория | Содержание |
|---|---|
| Пол | Пол и дополнительный параметр возраста. |
| Раса | Вид или происхождение персонажа. |
| Телосложение | Тип телосложения и рост. |
| Человеческая черта | Особенности характера и поведения. |
| Профессия | Специальность и уровень мастерства. |
| Здоровье | Состояние здоровья и возможные ограничения. |
| Хобби / увлечение | Занятия и интересы, иногда с уровнем мастерства. |
| Фобия / страх | То, чего персонаж боится. |
| Крупный инвентарь | Большой предмет или ресурс. |
| Малый инвентарь | Небольшая вещь, которую персонаж взял с собой. |
| Доп. сведение | Дополнительный факт о персонаже. |
| Спец. возможность | Особое действие, способное повлиять на партию. |

## 🏚 Встроенный набор «Стандартный»

В игре один встроенный набор — **«Стандартный»**. Он задуман как нейтральная основа для обычной партии: без привязки к мемам, фандомам или внутренним шуткам конкретной компании.

В нём есть три сценария катастроф, базовые варианты всех характеристик, возраст, рост и мастерство, специальные возможности, несколько размеров бункера, варианты планировки и финальные вопросы.

## ⚖ Финальная оценка

У каждого финального вопроса есть приоритет от **1 до 10**. Правильный ответ приносит соответствующее число баллов, неправильный — ноль.

Пример формата:

```text
Починена ли дверь в бункер? [10] | да
Есть ли чистая питьевая вода? [10] | да
Хватит ли еды на весь срок? [8] | да
Есть ли необходимые лекарства? [5] | да
Сможете ли прожить весь год? [1] | да
```

Для победы необходимо набрать не менее **70%** суммы всех приоритетов. Вопрос с приоритетом **10 — критический**: неправильный ответ хотя бы на один такой вопрос означает поражение независимо от общего процента. Приоритеты 8–9 сильно влияют на результат, но сами по себе не являются автоматическим поражением. Если вес не указан, используется 1.

## 🛠 Собственные наборы

В редакторе можно настроить сюжет, все 12 характеристик, дополнительные параметры возраста / роста / мастерства, размер бункера, планировку и финальные вопросы.

- Один вариант характеристики — одна строка.
- Несколько сюжетов разделяются строкой `---`.
- Подсказка к карточке записывается в квадратных скобках: `Инженер [Умеет чинить генераторы]`.
- Финальный вопрос: `Вопрос [приоритет] | да/нет`.
- Каждый размер и каждый вариант планировки записывается с новой строки.

Собственные наборы хранятся в браузере на текущем устройстве. Для переноса используйте **«Экспорт»** и **«Импорт»**.

## 🔐 Защита и приватность

Новая серверная архитектура предназначена для игры в знакомом комьюнити и защищает от обычного просмотра данных и подделки игровых действий.

- Полные значения карточек хранятся на сервере. Обычный игрок получает только собственные закрытые карточки и уже раскрытые карточки остальных участников.
- Ведущий может использовать функцию «Подсмотреть скрытое». Поэтому ведущим назначайте только тех, кому доверяете.
- Незавершённые голоса скрыты от всех, включая ведущего. Результаты становятся доступны после завершения голосования.
- Сервер проверяет игровые действия и права участника: игрок не может изменить чужую карточку, проголосовать за себя или отправить команду ведущего.
- Для комнат используются случайные 8-значные коды, сессионные токены, ограничения частоты запросов и проверка Turnstile (если она включена).
- Вкладка создателя не является сервером. Состояние партии хранится в Cloudflare Durable Object.
- Неактивные комнаты удаляются через 24 часа.

**Ограничение:** Cloudflare — доверенная сторона, которая хранит состояние комнаты. Это не сквозное шифрование от провайдера. Не используйте игру для передачи личных, медицинских, финансовых или иных конфиденциальных сведений. Код комнаты не публикуйте открыто.

## ☁️ Бесплатная серверная часть

Сайт остаётся статическим и публикуется через GitHub Pages. Сетевые комнаты работают на Cloudflare Workers и SQLite-backed Durable Objects. Для этого не требуется арендовать VPS или держать домашний компьютер включённым.

**Однократная настройка:** [инструкция по публикации бесплатного Worker](cloudflare/SETUP.md).

На Workers Free действуют дневные лимиты. При их превышении операции временно отклоняются до сброса квоты; чтобы оставаться в нулевом бюджете, не переходите на Workers Paid. Лимиты и тарифы могут меняться — сверяйтесь с официальной документацией Cloudflare:

- [Workers limits](https://developers.cloudflare.com/workers/platform/limits/)
- [Durable Objects pricing](https://developers.cloudflare.com/durable-objects/platform/pricing/)
- [Durable Objects limits](https://developers.cloudflare.com/durable-objects/platform/limits/)
- [WebSocket hibernation](https://developers.cloudflare.com/durable-objects/best-practices/websockets/)

## 🔧 Технологии

- **Frontend:** HTML, CSS, JavaScript без сборщика и фреймворков.
- **Публикация сайта:** GitHub Pages.
- **Комнаты и состояние игры:** Cloudflare Workers + SQLite Durable Objects.
- **Обмен в реальном времени:** WebSocket с серверной проверкой команд и персональными представлениями состояния.
- **Защита от автоматических запросов:** Cloudflare Turnstile (необязательно).
- **Авторизация:** Discord OAuth Authorization Code Flow с PKCE S256 (необязательно).
